# 门店活动效果分析 · 合成对照演示

用 16 家虚构门店的每日交易额，演示“合成对照（synthetic control）”式的活动效果比较：

- 选一家活动门店，从未参与活动的门店中找一组**非负、权重和为一**的组合，让它在活动前尽量贴近这家店。
- 活动前拟合只用**双方都有观测**的日期；活动期与活动后的数据**不参与挑权重**，活动后的差距单独画出。
- 停业（确认没营业）与漏报（缺数但可能营业）分开记录；不满足连续观察范围的门店逐条说明排除原因。
- 可以把任意对照店假装成活动对象做**安慰剂**比较，并直接展示“活动前拟合本来就很差”的反例。
- 点任意一天看加权明细；排除或锁定候选店，检查权重是否集中在单店、排除后结论是否稳定。

**结果只在明确的可比性假设下解释，不承诺识别真实因果。**

## 本地运行

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 产物在 dist/
npm run preview    # 预览构建产物
npm test           # 引擎单元测试（node --test）
npm run smoke      # jsdom 交互冒烟测试（22 项：选日、排除、锁定、安慰剂、弹窗）
npm run generate   # 重新生成虚构数据（确定性，种子 20261121）
```

`npm run e2e` 用 Playwright 截取 `test-results/` 下的整页截图（需要先 `npm run build && npm run preview`，
并在另一个终端以 `BASE_URL=http://127.0.0.1:4173` 运行）。

## 数据

- `data/dataset.json`：门店参数、活动、停业窗、漏报窗、本地冲击、水平突变、随机种子。
- `data/stores.json`：由 `tools/generate-data.mjs` 生成的逐日数据；每个门店每天的状态为
  `observed`（有观测，带 `v`）、`closure`（停业）或 `missing`（漏报）。
- 数据完全虚构，含 2 场活动、1 家权重集中店、1 家活动前拟合很差的门店，以及停业/漏报/本地冲击/水平突变等边界情况。

## 口径与规则

| 项目 | 规则 |
| --- | --- |
| 指标 | 门店每日营业交易额（元），虚构 |
| 拟合窗口 | 活动开始前 56 天 |
| 拟合日期 | 分析对象与**所有**正权重候选当日都有观测 |
| 权重 | `w_j ≥ 0`、`Σ w_j = 1`，最小化活动前平方误差；主动集法精确求解 |
| 活动后窗口 | 活动结束次日起 56 天，不参与权重 |
| 对照资格 | 窗口内无活动/本地冲击/水平突变；前后覆盖率 ≥ 90%；连续停业或漏报 ≤ 7 天 |
| 安慰剂 | 同一窗口、同一资格规则、同一求解器，把任一门店当作活动对象 |
| 稳定性 | 逐一排除正权重候选并重解权重，比较活动后合计差距 |

页面内“方法与口径”弹窗给出完整说明；“阅读边界”一节列出解释结果的假设与限制。

## 代码结构

```
src/
  engine/analysis.js   # 窗口、资格诊断、拟合、差距、稳定性、安慰剂扫描
  engine/solver.js     # 单纯形约束最小二乘（主动集精确解 + 投影梯度对照）
  components/          # 图表、候选表、单日明细、权重、稳定性、安慰剂、方法弹窗
data/                  # 虚构数据（dataset.json 为源，stores.json 为生成产物）
tools/generate-data.mjs
tests/engine.test.mjs  # 15 项引擎契约测试（权重约束、无泄漏、停业/漏报、安慰剂一致性等）
```
